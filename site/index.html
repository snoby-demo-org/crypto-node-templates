CivicNet Network

The CivicNet (CIVIC) network is a hybrid Proof-of-Work + Proof-of-Stake blockchain. This system entity groups the full-node components and related infrastructure in the Backstage catalog.

Consensus

  • Hybrid PoW + PoS
  • 60-second target block time
  • PoS ceiling of 30% — at most 30% of blocks can come from staking
  • PoS win condition: hash(kernel) < target * sqrt(UTXO)
  • Anti-cluster N=2 PoW to prevent a single miner dominating consecutive blocks
